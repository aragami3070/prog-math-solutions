# Граф документов и тем

## Семантика

Узлы: `document` (RFC/Internals) и `topic` (контролируемая taxonomy). Source tags показываются в карточке; добавлять их отдельными узлами только если это не дублирует taxonomy.

| Тип ребра | Что означает | Доказательство |
|---|---|---|
| `references` направленное | В документе есть ссылка на другой документ корпуса | Исходный URL, section ID, anchor |
| `has_topic` документ → тема | Присвоенная метка | Source/manual/model provenance и review state |
| `similar_to` ненаправленное | Алгоритм нашёл смысловую близость | Model revision, similarity, chunk evidence, threshold/version |

Общая тема не равна цитированию. Semantic similarity не означает историческое влияние, поддержку или противоречие. Не создавать рёбра `implements`, `supersedes`, `opposes` из догадки LLM. При необходимости таких типов позже потребовать отдельный подтверждающий источник и ручную проверку.

## Построение и хранение

Начать с references: canonicalize известные ссылки и RFC IDs; отделить fragment от идентичности документа, сохранив его как evidence. Внешние URL не посещать автоматически. Самоссылки и повторы свести в одну связь с набором evidence; не объединять разные документы по одинаковому заголовку.

`has_topic` хранить как document-topic relation, а не полную попарную clique всех документов одного тега. Таблицы PostgreSQL documents/topics/edges достаточны, отдельная графовая БД пока не нужна.

`similar_to` опционально после векторного поиска: ограниченные top-k соседи, дедупликация симметричных пар, запрет self edge. Threshold выбрать на dev и проверить pairwise precision человеком. Не показывать cosine как процент достоверности.

Рёбра привязаны к версиям документов/моделей. При обновлении/удалении stale evidence удаляется или перестраивается. Граф ссылок не зависит от доступности LLM/Qdrant.

## Интерфейс

Cytoscape.js; по умолчанию эго-граф выбранного документа, depth=1, предел 100 узлов/300 рёбер, серверный максимум 200/600. Пределы стартовые, проверить на мобильном устройстве. Не отправлять весь корпус в браузер и не рисовать тысячи узлов по умолчанию.

Цвет и форма узлов по типу, легенда и разные стили рёбер; фильтры источника/типа связи/темы. Клик на узел открывает карточку, клик на ребро — объяснение и evidence. Есть список соседей как доступная альтернатива canvas. Сообщать об обрезке и давать явное расширение.

API отдаёт nodes, edges, edge types, provenance, generation, `truncated`. Положение узлов в layout не является дополнительным доказательством близости. Качество графа проверяется на рёбрах, не по красивой картинке.
