# Проектные скиллы

Локальные инструкции нового проекта. Они лежат в запрошенной `.agent/skills/`, не установлены в глобальное хранилище и не считаются автоматически обнаруживаемыми клиентом. Для применения указать точный путь SKILL.md. Правила и решения находятся в [контексте](../README.md); скиллы дают маршрутизацию и проверяемые инварианты, а не дублируют всё ТЗ.

| Скилл | Когда применять |
|---|---|
| [rust-corpus](rust-corpus/SKILL.md) | HTML-сбор Internals/RFC, парсинг, экспорт, completeness |
| [rust-retrieval](rust-retrieval/SKILL.md) | Tantivy, леммы, опечатки/синонимы, Qdrant и fusion |
| [rust-topic-ml](rust-topic-ml/SKILL.md) | Таксономия, Qwen-классификация, embedding-конфигурация, разметка и оценка |
| [rust-knowledge-web](rust-knowledge-web/SKILL.md) | Axum/OpenAPI, React-интерфейс и граф, эксплуатация приложения |

Читать только подходящий скилл и указанные для конкретной задачи документы. Ни один скилл не разрешает внешнюю публикацию, массовый сбор без gate, покупку ресурсов или неограниченную загрузку/обучение моделей.
