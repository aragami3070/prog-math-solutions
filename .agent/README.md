## Зафиксированные решения

- Rust + Axum + PostgreSQL; React + TypeScript + TanStack Query/Router. Zustand добавлять только при появлении нужного локального UI-состояния.
- Backend: router → use case → repository → PostgreSQL через SQLx. Транзакция приходит в use case из router; repository использует её без собственного begin/commit. Зоны api/repository — отдельные файлы, зоны use_cases — каталоги с файлом на сценарий; документы в sources. Типы ошибок — в соседних errors.rs. Подробные правила в current-slice.
- SQL — только проверяемые макросы SQLx (`query!`, `query_as!`, `query_scalar!`), многострочный читаемый формат. Utoipa также форматировать многострочно. Метаданные `.sqlx/` хранить в Git и обновлять через `cargo sqlx prepare -- --all-targets`; локальная компиляция использует `SQLX_OFFLINE=true` из `.env`.
- Модели — `models/{sources,crawls,statistics,pagination}.rs` с явными импортами из соответствующего модуля. Общий model.rs не возвращать.
- Текущий API локальный, без авторизации и токенов. `HTTP_BIND` ограничен loopback-адресами; конфигурация автоматически загружается из `.env`. Авторизация понадобится при внешнем развёртывании.
- **Tantivy** как текстовый движок, обратный индекс и BM25 внутри backend. API проверяется без frontend; CLI не является условием готовности. Не добавлять второй текстовый движок без изменения требований.
- Qdrant для векторов на соответствующем этапе. Qwen из Hugging Face — кандидат для фоновой multi-label классификации; embedding-модель отдельная.
- Основной корпус — минимум 5 000 уникальных содержательных тем Internals с подтверждённо полным HTML; RFC дополнительно. Пагинация, сообщения внутри темы и chunks не увеличивают этот счётчик.
- Классификация по контролируемой таксономии, исходные теги отдельно от машинных. Граф явно различает ссылки, общие теги и вычисленное сходство.
- Все семь критериев домашки имеют отдельный артефакт и проверку с учётом уточнения про свободный выбор интерфейса. Граф и AI-теги не заменяют работающий поиск, экспорт, индекс и оценку релевантности.
- Локальная разработка; массовый обход, установка моделей и внешняя публикация не выполнялись в рамках обновления контекста.
