# Нагрузка и реплики (P9, часть, проверенная на одной машине)

Измерено 2026-11-05: 1 CPU, 2 ГБ RAM, всё на одном хосте (API, PostgreSQL, Qdrant, воркер эмбеддингов, сам генератор нагрузки), release-сборка, 4943 документа. Нагрузка открытого цикла (`scripts/load-check.py`): запросы уходят с фиксированной частотой независимо от скорости ответов, запросы оценки в фиксированном порядке, `page_size=20`.

| режим | целевая частота | ошибок | достигнуто, запр/с | медиана, мс | p95, мс | p99, мс |
|---|---|---|---|---|---|---|
| лексический | 5/с × 60 с | 0 из 300 | 5.0 | 37 | 66 | 94 |
| лексический | 10/с × 30 с | 0 из 300 | 10.0 | 36 | 66 | 91 |
| hybrid | 2/с × 30 с | 0 из 60 | 2.0 | 218 | 391 | 543 |
| hybrid | 3/с × 30 с | 0 из 90 | 3.0 | 200 | 320 | 574 |
| hybrid | 5/с × 60 с | 0 из 300 | 4.5 | 4648 | 12208 | 14479 |

**Вывод.** Гипотеза плана «p95 ≤ 1 с при 5 запросах/с» выполняется для лексического режима (с большим запасом, до 10/с) и **не выполняется для hybrid на этой машине**: при 5/с очередь растёт (медиана 4.6 с), потому что один запрос занимает около 200 мс CPU (эмбеддинг запроса в воркере плюс два списка по 100), а CPU один. Держит hybrid примерно 3 запроса/с. Это предел этой машины, а не поиска: воркер эмбеддингов и API делят один процессор. Лечится числом ядер или вынесением воркера эмбеддингов на отдельный узел; сколько именно даст — не измерено.

**Реплика по снимку.** Копия каталога одного поколения индекса в другой каталог, второй процесс API на нём: ответы по всем 84 запросам в режимах lexical и hybrid (168 пар) совпали с основным экземпляром, включая номер поколения. Это подтверждает схему «один индексатор строит поколение, читатели получают неизменяемую копию». Не проверено: проверка контрольной суммы манифеста читателями (в манифесте её нет), атомарное переключение читателя на новое поколение под нагрузкой кроме автообновления одного процесса, readiness с учётом поколения.

**Память (RSS)** в конце прогонов: API около 75 МБ, воркер эмбеддингов около 800 МБ, Qdrant около 70 МБ. Воркер — основной потребитель памяти.

**Не сделано в P9:** образ `Dockerfile` и сервис `api` в `compose.yaml` написаны, но не собирались и не запускались; ВМ-развёртывание, K3s, rolling update, балансировка, HPA, отдельный узел NLP — не делались и на этой машине не проверяемы. Общий лимит запросов к источникам (crawl budget) при нескольких репликах не менялся: сбор остаётся в одном процессе.
